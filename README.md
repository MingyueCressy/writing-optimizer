# Writing Optimizer ✍️

> 一套可复用的**双层批阅页**工具：底层是答卷正文，上层是批注图层。
> 给妹妹批考研英语，给自己批雅思，同一套引擎换内容即可。

**在线预览**：https://mingyuecressy.github.io/writing-optimizer/
**受众（阅读）视角**：https://mingyuecressy.github.io/writing-optimizer/?mode=view

---

## 特点

- **6 种标记形态**：波浪 / 圈 / 矩形框 / 高亮 / 下划线 / 双下划线，每种 4 个预设色
- **先选工具 → 点词或划选**：点单个词，或拖选一段（跨行自动分段）都能标
- **多层叠加**：一段话可被框线框住，段内某几个词另用圈/波浪/高亮单独标记（互不冲突）
- **可修改标记**：点已标处 → 换形态 / 换颜色 / 改批注 / 删除（波浪可改矩形框）；重叠处弹出拾取器让你选编辑哪一层
- **批注卡浮在词旁**：点词出卡，点空白收起
- **双视角**：编辑（批注者）⇄ 阅读（受众），右上角一键切换
- **类纸排版**：米色纸底 + Georgia 衬线 + 大行距，竖屏（手机/iPad 爽看）
- **总评**：五维评价 + 核心问题 + 背诵清单
- **数据驱动**：批注数据独立 JSON（`data/*.json`），换作文只改数据

## 怎么用

### 编辑视角（批注者）

1. 打开 `index.html`（浏览器/手机/iPad 均可）
2. 在右侧工具列点一个**标记形态**（波浪/圈/矩形框/高亮/下划线/双下划线）→ 弹出**色板选颜色**
3. 然后**点单个词**，或**拖选一段文字**（跨行也行）→ 应用标记，并弹出批注框
4. **点已标记处** → 打开编辑框，可**换形态 / 换颜色 / 改批注 / 删除**
5. 工具列小工具：撤销 ↩ / 清样版 📄 / 总评 📋

### 阅读视角（受众）

- 右上角按钮切换：显示 **✏️ 笔** = 当前阅读态，点它进编辑；显示 **📖 书页** = 当前编辑态，点它进阅读
- 阅读视角**没有工具列**，只能看不能改
- 点标注的词 → 弹出批注卡；点空白处 → 收起
- 点右上角得分 → 打开总评
- 也可用 URL 参数 **`?mode=view`** 直接进入阅读视角

## 界面约定

| 项 | 约定 |
|---|---|
| 比例 | 9:16 竖屏，一页一篇小作文；大作文两页 |
| 底纸 | 米色 + 纸纹 |
| 正文 | Georgia 衬线体 + 大行距 |
| 批注 | 思源黑体（中）+ Times New Roman（英） |
| 🔴 错词圈 | 拼写/用词错 |
| 🟠 句法波浪 | 语法/词性/搭配 |
| 🟢 亮点高亮 | 写得好 |
| ⚠️ 硬伤标记 | 内容矛盾等致命扣分 |
| 🔵 模板句式 | 可套用空壳 |
| 🟣 纯批注 | 只挂意见不改文字 |

## 数据格式（换新作文）

批注数据在 `data/*.json`：

```json
{
  "meta": { "title": "…", "score": "7 / 10" },
  "blocks": [
    { "type": "para", "text": "正文…[[error:错词|批注意见]]…" }
  ],
  "summary": { "dims": [...], "priority": [...] },
  "recite": [ { "wrong": "…", "right": "…" } ]
}
```

正文里用 `[[类型:被标的词|批注意见]]` 内嵌标注，类型：
`error / grammar / good / fatal / template / note`。

> ⚠️ **坑**：浏览器用 `file://` 打开时 `fetch()` 被 CORS 拦截，读不了外置 JSON。
> 所以数据**内联在 `index.html` 的 `<script id="app-data">` 块**里（`EMBED=true`）。
> 改完 `data/*.json` 后，**需要重新内联进 HTML** 才能生效。

## 目录

```
.
├── index.html                     # 批阅工作台（单文件应用）
├── data/
│   └── 2025-english1-essayA.json  # 批注数据（2025 考研英语一小作文）
└── (原卷/ 不进仓库)
```

> ⚠️ **原卷留档铁律**：手写原卷必须存进本地非公开目录
> `~/WPS Sync/Senior/考研英语原卷/`，**批阅时对照原卷核**，不要只对着转写文本批。
> 原卷含学生隐私，**不进公开仓库**（已在 `.gitignore` 排除）。
> 命名：`<年份>考研英语<题型>.jpg`，例 `25考研英语小作文.jpg`。
