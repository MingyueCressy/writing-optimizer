# Writing Optimizer ✍️

> 一套可复用的**双层批阅页**工具：底层是答卷正文，上层是批注图层。
> 给妹妹批考研英语，给自己批雅思，同一套引擎换内容即可。

**在线预览（批阅工作台）**：https://mingyuecressy.github.io/writing-optimizer/
**受众（阅读）视角**：https://mingyuecressy.github.io/writing-optimizer/?mode=view

---

## 特点

- **7 种标记形态**：波浪 / 圈 / 高亮 / 下划线 / 双下划线 / 删除线 / 补充信息（∇），每种多预设色
- **先选工具 → 点两下圈定范围**：先点选中范围的**首词**，再点**末词**，中间范围即被标上（跨行自动分段）
- **多层叠加**：一段话可被整段高亮/标记，段内某几个词另用圈/波浪/删除线单独标记（互不冲突）；点重叠处弹出**拾取器**选层编辑
- **可修改标记**：**在未选择任何标注工具的情况下**，点已标处 → 换形态 / 换颜色 / 改批注 / 删除
- **批注卡浮在词旁**：点词出卡，点空白收起
- **编辑原文**：发现转写（OCR）错误可就地改正文，标记偏移**自动平移**不跑位
- **范文面板**：📖 查看范文，与批注对照；修订要点附在范文末尾
- **双视角**：编辑（批注者）⇄ 阅读（受众），底部居中一键切换
- **类纸排版**：米色纸底 + Georgia 衬线 + 大行距，竖屏（手机/iPad 爽看）
- **总评**：五维评价 + 核心问题 + 背诵清单，且**总评内容可编辑**、随导出一起走
- **版本守卫**：线上 `app-data` 带 `rev` 时，本地旧缓存自动作废，不会用旧批注覆盖新版
- **数据驱动**：批注数据独立 JSON（`data/*.json`），换作文只改数据

## 怎么用

### 编辑视角（批注者）

1. 打开 `index.html`（浏览器 / 手机 / iPad 均可）
2. 在右侧工具列点一个**标记形态** → 弹出**色板选颜色**
3. 然后**点两下圈定范围** → 应用标记，并弹出批注框：

   - **选单个词**：在目标词上**连点两次**（此词即首尾）→ 只标这一个词
   - **选一段**：先点这段的**首词**，再点**末词** → 首末之间的整段被标（可跨行，自动分段）
   - 无论选一词还是一段，操作本质相同：**都是“点首词 → 点末词”**；点同一个词两次，就是首尾同词，即只选一个词
4. **在未选任何标注工具时**，**点已标记处** → 打开编辑框，可**换形态 / 换颜色 / 改批注 / 删除**；重叠处弹拾取器选层
5. **改动自动暂存**到浏览器本地（刷新/关页再开都不丢）
6. 工具列小工具：撤销 ↩ / **导出 💾 / 导入 📥** / 🔄 加载最新版

### 保存与上线流程（重要）

- **本地暂存**：编辑时自动存进浏览器 `localStorage`（仅本机，刷新不丢）
- **导出 💾**：把**当前批注数据**下载成 JSON（标记 + 总评 + 范文 + 正文快照）；内置浏览器拦截下载时会**同时给出 Base64 复制框**兜底
- **上线**：把导出的 JSON 发给酸奶学姐 → 合并进 `data/*.json` → 重新内联进 `index.html` → commit + push → **线上 + 受众版（`?mode=view`）同步更新**
- **导入 📥**：拿到某个 JSON 可一键套用（覆盖当前）
- **🔄 加载最新版**：丢弃本地改动，回到线上版本

> ⚠️ 本地暂存 ≠ 上线。读者（含 `?mode=view`）看到的是 **GitHub 线上的版本**，只有 commit+push 后才更新。

### 阅读视角（受众）

- 底部居中按钮切换：显示 **✏️ 笔** = 当前阅读态，点它进编辑；显示 **📖 书页** = 当前编辑态，点它进阅读
- 阅读视角**没有工具列**，只能看不能改
- 点标注的词 → 弹出批注卡；点空白处 → 收起
- 点右上角得分 → 打开总评；**∇ 补充信息** 在阅读态也可点开
- 也可用 URL 参数 **`?mode=view`** 直接进入阅读视角（锁定编辑入口）

## 界面约定

| 项 | 约定 |
|---|---|
| 比例 | 竖屏（手机 / iPad 优先），上下滑动滚动阅读，不分页、不左右翻页；大作文小作文同为连续一页 |
| 底纸 | 米色 + 纸纹，答题纸满填充（去黑边 / padding / 圆角 / 阴影） |

| 批注 | 思源黑体（中）+ Times New Roman（英） |
| header | 标题（左，约 4/5）+ 得分与评语（右，约 1/5）同行；标签串次行占满 |
| 🔴 错词圈 | 拼写 / 用词错 |
| 🟠 句法波浪 | 语法 / 词性 / 搭配 |
| 🟢 亮点高亮 | 写得好 |
| ⚠️ 硬伤标记 | 内容矛盾等致命扣分 |
| 🔵 模板句式 | 可套用空壳 |
| 🟣 纯批注 | 只挂意见不改文字 |

## 数据格式（换新作文）

批注数据在 `data/*.json`：

```json
{
  "meta": { "title": "…", "score": "6 / 10" },
  "blocks": [
    { "type": "para", "text": "正文…[[error:错词|批注意见]]…" }
  ],
  "summary": { "dims": [...], "priority": [...] },
  "recite": [ { "wrong": "…", "right": "…" } ]
}
```

正文里用 `[[类型:被标的词|批注意见]]` 内嵌标注，类型：
`error / grammar / good / fatal / template / note`。

> ⚠️ **坑**：浏览器用 `file://` 打开时 `fetch()` 被 CORS 拦截，读不了外置 JSON。
> 所以数据**内联在 `index.html` 的 `<script id="app-data">` 块**里（`EMBED=true`）。
> 改完 `data/*.json` 后，**需要重新内联进 HTML** 才能生效。
> 数据里带 `rev`（如 `2026-09-29-v4.9`）时，本地旧 `localStorage` 会被版本守卫丢弃。

## 作文存档规范

工作台会不断迭代出很多篇作文，每篇定稿（或阶段性定稿）都做一份**离线存档**，
放在本地 `~/WPS Sync/Senior/考研英语批阅/存档/`，**每篇一个子文件夹**：

```
存档/
├── README.md                         # 存档目录总说明
└── <年份>英<一/二><大/小>作文·<主题概括>/
    ├── 管理版.html                    # 编辑 + 阅读双视角，带工具列，可继续批改
    ├── 阅读版.html                    # 固定只读受众视角（隐藏工具列 / 视角切换 / 加载最新版）
    └── 批注数据.json                  # 合并后的批注数据（一个文件，两种用途）
```

**子文件夹命名**：`<年份>英<一/二><大/小>作文·<主题概括>`
- 例：`2025英一小作文·校园工艺展回信`、`2025英一大作文·耐用消费品图表`
- 主题概括用简明中文点出题目内容，**一看就懂是哪道题**即可。

**三种文件**：
| 文件 | 说明 |
|---|---|
| `管理版.html` | 单文件完整应用，双击即开、离线可编辑（批注 / 改原文 / 改总评 / 导出）|
| `阅读版.html` | 只读版：写死 `viewing=true` + `body.locked`，并移除“🔄 加载最新版”（无本地暂存，该按钮无效）|
| `批注数据.json` | **合并数据**：同时携带 `marksMap`（页面内联数据源）与 `marks`（工作台 📥 导入格式），一个文件两用 |

**为什么合并成一个 json**：早期存档分 `app-data.json`（页面内联格式）与 `marks导入版.json`（工具导出的 `{tool, version, paper, savedAt, marks, …}` 格式），两份内容其实高度重叠。现在在一个文件里同时写 `marksMap` 与 `marks`，既能当页面数据源，也能直接 📥 导入，减少冗余。

**生成方式**：以最新 `index.html` 为骨架、替换其 `<script id="app-data">` 内容 →
产出 `管理版.html`；再对 `管理版.html` 写死阅读视角 + 删“加载最新版”→ 产出 `阅读版.html`。
